# Polynomial Calculator (Linked List Implementation)

A simple **Polynomial Calculator** in C using **Linked Lists only**.  
Supports:
- Adding polynomials
- Multiplying polynomials
- Displaying polynomial in human-readable form

## Example

P1 = `3x^2 + 2x + 5`  
P2 = `4x^3 + x + 1`

**Output:**
Sum: `4x^3 + 3x^2 + 3x^1 + 6x^0`
Product: `12x^5 + 8x^4 + 17x^3 + 7x^2 + 7x^1 + 5x^0`
